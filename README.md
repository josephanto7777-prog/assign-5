# Joseph Anto — Portfolio Website

A responsive personal resume and portfolio website built with HTML, CSS, JavaScript, and Node.js/Express.

## Project structure

```text
joseph-anto-portfolio/
├── public/
│   ├── cv.html
│   ├── style.css
│   └── script.js
├── server.js
├── package.json
├── package-lock.json
├── .gitignore
└── README.md
```

## Run locally

1. Install Node.js (version 18 or later).
2. Open this project folder in a terminal.
3. Run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:3000` in your browser.

## Customize

Update the text and links in `public/cv.html` to keep your contact details, education, skills, experience, projects, and certifications current.

## Notes

- The site is served by Express from the `public` folder.
- Do not upload `node_modules` or `.git` to GitHub.
- Check all public contact details and profile links before publishing.
